# battle_hud_v3 战斗交互

## 目标
- 恢复移动后可执行普通攻击、武功、道具、待机、取消移动的完整 SRPG 流程。
- 让 `battle_hud_v3` 成为唯一战斗交互 HUD，移除旧 `ActionPanel` 的职责。
- 保留现有 `_execute_attack`、技能、道具执行逻辑，只重做状态切换与 UI 入口。

## 主流程
1. 玩家阶段 `IDLE`
   - 左键己方未行动单位：进入 `UNIT_SELECTED`
   - 显示移动范围 `move_range`（蓝）
2. `UNIT_SELECTED`
   - 左键可达格：移动，进入 `MOVED_AWAIT_ACTION`
   - `V`：打开武功子面板
   - `Esc` / 右键：取消选择，回到 `IDLE`
3. `MOVED_AWAIT_ACTION`
   - 显示攻击范围 `attack_range`（红）
   - HUD 右下显示动作菜单：`攻击 / 武功 / 道具 / 待机 / 取消移动`
   - 左键红区内敌人：直接普通攻击，执行后结束行动
   - `A`：强调进入攻击模式，保留红色范围并提示点击敌人
   - `V`：打开武功子面板，选中后进入 `SKILL_TARGETING`
   - `B`：打开道具子面板，选中后进入 `ITEM_TARGETING`
   - `Z`：待机，直接结束行动
   - `Esc` / 右键：取消本次移动，单位回到移动前位置，回到 `UNIT_SELECTED`
4. `SKILL_TARGETING`
   - 左键合法目标格：执行技能
   - `Esc` / 右键：回退到进入前的状态
5. `ITEM_TARGETING`
   - 左键合法目标单位：执行道具
   - `Esc` / 右键：回退到进入前的状态

## 状态机
| 状态 | 进入方式 | 可见 UI | 退出方式 |
| --- | --- | --- | --- |
| `IDLE` | 默认 / 行动结束 / 取消选择 | 无动作菜单 | 选中己方单位 |
| `UNIT_SELECTED` | 选中己方单位 / 取消移动 | 蓝色移动范围，角色卡 | 移动、武功、取消 |
| `MOVED_AWAIT_ACTION` | 移动完成 | 红色攻击范围，动作菜单 | 攻击、武功、道具、待机、取消移动 |
| `SKILL_TARGETING` | 武功子面板选中技能 | 技能范围，动作菜单保留 | 技能执行、回退 |
| `ITEM_TARGETING` | 道具子面板选中物品 | 道具目标范围，动作菜单保留 | 道具执行、回退 |

## 键鼠映射
- 左键：
  - `IDLE` 选中己方单位
  - `UNIT_SELECTED` 选择落点
  - `MOVED_AWAIT_ACTION` 直接点红区敌人发动普通攻击
  - `SKILL_TARGETING` / `ITEM_TARGETING` 选择目标
- 右键 / `Esc`：
  - 回退一层
  - 在 `MOVED_AWAIT_ACTION` 撤销本次移动
- `A`：攻击
- `V`：武功
- `B`：道具
- `Z`：待机

## UI 呈现
- 左下角色卡：
  - 仅在 `UNIT_SELECTED` 显示，用于浏览己方单位信息
- 右下动作菜单：
  - 仅在 `MOVED_AWAIT_ACTION` 或其派生目标选择阶段显示
  - 禁用不可执行动作，例如攻击范围为空、无可用道具
- 武功子面板：
  - 展示 3 个技能槽
  - 显示 `CD` / `已用尽`
- 道具子面板：
  - 列出当前可用消耗品和数量

## 设计取舍
- 普通攻击保留 Fire Emblem 风格“移动后直接点敌人即可攻击”。
  - 这样不引入额外攻击子状态，学习成本更低。
  - `A` 仍保留，作为键盘用户的显式入口和提示强化。
- 点击空白格不再默认待机。
  - 旧逻辑误触成本高，且容易与“点击敌人没反应”混淆。
  - 待机收敛到 `Z` 和动作菜单按钮。
- 取消移动是真正撤销位移，而不是简单清空选中。
  - 符合 SRPG 常规预期，也避免单位在已移动位置被错误留在未行动状态。
